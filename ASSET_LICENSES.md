# Asset sources and licenses

## Rider–Waite card images

- Artist: Pamela Colman Smith
- Original deck publication: 1909
- Integrated source: [`@cometpisces/tarot-kit-images` 0.2.0](https://www.npmjs.com/package/@cometpisces/tarot-kit-images)
- Files used: all 78 PNG images in `assets/cards/`
- Changes in this project: renamed to match local card IDs; displayed with Sakura borders, shadows, and responsive sizing

The source package states that its code and mappings are MIT-licensed and that the original Rider–Waite images are believed to be in the public domain in many jurisdictions due to their age. Copyright status can vary by jurisdiction. For commercial use, verify the applicable rules where the service is operated.

No images from modern commercial “pink Rider–Waite” products were copied. The pink appearance in this project is created by original CSS framing, glow, card-back, and interface treatments.
